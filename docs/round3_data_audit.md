# 第三轮数据审计

固定公开源 RCAEval，revision 为 `afeacb11bcc94dadfd1c8f483ee4377b2b8b614e`。

保留原 RE1-OB 125 条，下载同应用 RE2-OB 五类故障 75 条。官方索引共 735 条：RE1 每应用 125、RE2 每应用 90、RE3 每应用 30，三个应用共 735。RE2 每应用包括 15 条 socket 故障；当前 ontology 不支持，因此排除。本轮不使用 RE3 或其他应用。新数据存在日志、traces，但仅下载和使用 metrics。

## 样本和防泄漏

200 条案例各产生一个因果汇总窗口，200 个遥测指纹组；没有用重复窗口虚增案例数。按原始案例/指纹分组后划分，原 split 不变，旧测试改称 regression。train 65 / model_validation 20 / calibration 20 / gate_selection 55 / regression 15 / test 25。源数据、每文件 SHA256、窗口、候选和标签记录在 `data/round3/manifest.json`；分割与摘要复制在 `outputs/round3/`。反映复制可疑性的全时序、基线和归一化观测指纹没有发现跨组副本；源采集谱系未知，不能据此证明案例统计独立。

标签只由官方注入元数据映射到既有五类标签，候选从指标列构建；全部 200 条的正确根因均在候选中，覆盖率 100%。split、suite、路径、故障标签与注入元数据不能进入序列化输入；文件名用于审计，不作为模型特征。pilot 的两条试读案例固定为 TRAIN。

## 预处理边界

基线 [-300,0) 秒，故障观测 [0,60] 秒，窗口依赖官方已知注入时间。没有检测延迟评价。数据本身的未声明单位保持原样，不擅自做单位换算。缺失值保留缺失状态，不从未来补齐。指纹计算时部分全空列出现 numpy Mean of empty slice 警告；这并不生成新数值证据，adapter 对全空统计保留缺失并记录比例。

RE2 使用不同指标 schema（包括 diskio、socket 遥测名）；遥测中的 socket 并不意味着纳入 socket 故障标签。数值词表仅从 65 条 TRAIN 的真实 metric names 提取。全部输入候选和 token 保留情况在每条 predictions 的 serialization 字段记录。

## 解释范围

这些是受控注入案例。新测试是相同应用、不同基准套件的 25 条此前未做预测的案例，模型选择冻结后才评估。不代表生产故障、不证明新应用或真实告警起点泛化。旧 15 条 regression 已被反复查看，只检验兼容性，不作为新的独立确认性证据。
