# DecisionOS-SRE 第五轮协议

execution_scope: mvp。预算与选择规则在训练前封存于 outputs/round5/protocol.json。

保留原有 400 个案例及全部划分：train 165、validation 40、calibration 40、gate 85、Online Boutique 历史回归 15+25、Sock Shop 历史回归 30。没有新增独立案例，所有已打开的测试集均明确作为回归集。

在原均值特征后附加六个时间特征：相对基线的 p10 / p90、波动、60 秒线性趋势、后半段与前半段之差、存在标记。标准化尺度沿用基线标准差与数值下限；裁剪后使用固定 signed-log 变换。仅读取基线 [-300,0) 与观测 [0,60] 秒，窗口由公开注入起点确定；不评估起点检测。数值分支仅使用保留在输入预算内的指标。旧文本、候选顺序、旧数值向量保持不变，新列零填充初始化。

四组实验：旧均值继续训练对照 seed43；时间特征 seed42 / 43 / 44。每组相同学习率 0.0003、batch16、最多 2000 次更新，60 个无改进 epoch 后早停。共享 ModernBERT 编码器冻结，仅训练诊断头；每例仍只调用一次编码器。

将上一轮模型作为现任对照。模型选择首先要求 OB 验证联合准确率至少 95%、SS 至少 90%，再比较四来源联合准确率均值、总体联合准确率、最后 sum NLL。数值只是保留约束，工作质量目标仍为 90% / 90% / 85%。工作目标来自此前默认假设，并非用户提供的具体数值。calibration / gate / regression 不用于选择模型；回归打开后本轮不再调参。

校准与门控分别只使用各自划分。经验联合错误率上限仍为 5%、至少接受 30 个案例组。已有 gate 被多轮复用，不能当成新的独立安全保证。门控成功也只允许接受诊断，不执行运维动作。

验收包括时间边界测试、旧表示指纹一致、零填充迁移、训练抽样 ID 隔离、缓存与完整模型一致、CPU checkpoint 重载、真实 HTTP、CPU 性能、缺失证据与候选变换，以及逐案例回归记录。重复验证选择有过拟合风险；需新的独立 Online Boutique 数据才能重新确认泛化目标。
