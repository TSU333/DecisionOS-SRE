# 第九轮训练数据增强协议

execution_scope: mvp。训练前冻结4组实验及发布保护，机器协议见 outputs/round9/protocol.json。

基于原始TRAIN数据审计：165例中有1例RE1-OB在[onset,onset+60]没有观测，无法提供有效故障证据。本轮保留其原始记录、标签、分组、划分与父模型历史，只不再抽入训练。其余164例每例生成2个视图，共328个。它们不是新增独立案例，训练/验证/校准/门控/历史回归原分区不变。

lag15视图模拟末尾15秒观测延迟：遮蔽(45,60]秒。gap15_30视图模拟中间缺测：遮蔽[15,30)秒。决策时刻仍为onset+60，baseline仍为[-300,0)，不使用决策之后的数据。缺失比例以原60秒完整采样行数为分母，不把缺测当作完整短窗口；均值、z值、观测数、截止时间和temporal-v1均由剩余观测重新计算。标签、候选集合与原始run/group保持不变；视图元数据不进入模型输入。

按cohort平衡抽取原案例，再按固定概率选原输入或两个视图之一；每个案例一次抽样只贡献一个视图，不因视图数改变案例权重。原案例抽样与视图选择使用独立随机流。训练日志同时保留原始run_id与view_id；校准、门控和验证不生成视图。

固定4组：有效证据过滤但不增强的对照；50%视图联合头；75%视图联合头；50%视图故障头。全部seed46、lr0.0001、batch16、weight_decay0.01，最多2200更新，80个无改进epoch早停，无Dropout/标签平滑。全部从第五轮默认模型初始化，共享主干冻结并缓存每个确定输入的精确表示。联合头可更新根因与故障头；故障头方案冻结根因。每例正式推理仍一次主干调用，推理API/数值表示不变。

只使用原40条验证：保留OB联合≥95%、SS≥90%，再比较四cohort联合均值、总体联合、NLL，包含现任模型。冻结后只验收一个候选；任一历史cohort根因/故障/联合准确率下降则保留现任，不尝试次优模型，不再改参。本轮改进方向来自训练证据质量审计，历史回归仅作预设发布保护，全部是已打开的旧案例。

门控保持经验联合错误率≤5%、至少30条。重复验证与门控有选择偏差，不能宣称独立自动接受安全。90%根因/90%故障/85%联合是此前工作假设，并非用户原Prompt的明确数值。仍需新独立数据确认泛化，不执行运维动作。

验收：TRAIN限定、未来数据与遮蔽值不影响视图、缺失比例正确、标签/分组不变、空证据过滤、按原案例抽样、视图文件校验与抽样审计、缓存/完整推理一致、冻结权重校验、CPU重载、HTTP、历史回归/消融与CPU性能。相同旧例数据上的改善仅作历史回归报告。
